etherfly.github.io
==================

This is my GitHub user page, hosting two browser games:

- [Ectoblade](https://etherfly.github.io/ectoblade/), a mouse-controlled action prototype.
- [Rat Rider Dominique](https://etherfly.github.io/rrd/core.html), an HTML5 RPG.

For the latest version, head to [Rat Rider Dominique's repository](https://github.com/Etherfly/rat-rider-dominique).

Ectoblade's source lives in [its own repository](https://github.com/Etherfly/ectoblade). To update it, run `npm ci`, `npm test`, and `npm run build` there with Node.js 24 or newer. Replace this repository's `ectoblade/` contents with the resulting `dist/` contents, then commit and push `master`. GitHub Pages publishes the repository root. Keep the homepage and `rrd/` in place when updating the game.
